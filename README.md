# chra-media

Media for the Instagram page **Chra · چرا** ([@chra.krd1](https://www.instagram.com/chra.krd1/)) — Quran and Seerah in Kurdish.

Files here are served by GitHub Pages so Instagram can fetch them when a reel is published:

- `videos/` — approved reels (MP4)
- `covers/` — reel cover images (JPG)
- `brand/` — logo and lantern mark

Base URL: https://mrsaro1000.github.io/chra-media/
